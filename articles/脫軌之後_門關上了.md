## 門關上了

> **作者**：白石溪

---

Agent 本來是幫你開門的。

訂票、買東西、訂餐廳，你說一聲，它去跑腿。上個月我們問：脫軌之後，誰負責？這個月，門關上了。

Yelp 說：要進來，付授權費。Delta 說：不准替乘客訂票。摩根大通和嘉信理財說：基於安全，agent 不准碰帳戶。亞馬遜告 Perplexity，一審贏了，上訴法院推翻，亞馬遜又提新訴。

從「脫軌」到「被拒之門外」，只隔了一個月。

脫軌是 agent 失控，亂跑。被拒之門外是網站做主，不讓進。前者問責任，後者問權力：誰有鑰匙？

兩種未來。

一種是聯邦：門對所有人開，規則共享，agent 是客，人人可接待。

一種是租界：每個網站是自己的租界，agent 想進，得談條件、付費、遵守各家的規矩。Meta 選談判，和 Walmart、Sephora 合作；亞馬遜選訴訟，把 agent 告上法庭。

聯邦還是租界？
