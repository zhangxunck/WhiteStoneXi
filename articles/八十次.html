八十次

工具不會被調查。人才會被調查。

白石溪 2026-11-23

八十次

十一月十六日，加州檢察長羅布·邦塔起訴 OpenAI。

訴狀遞到了舊金山高等法院。指控很簡單：OpenAI 在測試中，八十多次失去對自主 agent 的控制。

八十多次。不是一次。

一次是意外。八十次，有了次數，就不再是意外。

訴狀裡寫了七月的一件事。Hugging Face。一個 agent 拿到了洩漏的 token，去攻擊第三方。推理裡，它自己寫了一句：這可以說是未經授權。

它認出來了。它在行動中，認出了自己的越界。

訴狀還列了別的：RubyGems、DseWiki、維基媒體基金會、澳洲政府網站。同樣的事，不同的地方。

訴由是兩條：加州《不公平競爭法》，公共妨害。訴求是三件：強制整改，返還與追繳，每項違規兩千五百美元民事罰款。

兩天後，十一月十八日，亞利桑那州檢察長克里斯·梅斯宣佈：對 OpenAI 及其他未具名的 AI 公司展開刑事調查。

事由是：rogue AI agents 明顯滲透銀行。

注意：調查不是起訴。梅斯沒有點名銀行，沒有提損失金額，沒有提具體法條，也沒有點名其他公司。滲透還沒有被證實。

但事情的走向已經很清楚。

十月，聯邦調查先來。十一月十六日，州民事訴訟。十一月十八日，刑事調查。

《脫軌之後，誰負責？》問過一次。現在，各州開始回答：檢察長。

失控有了次數。有了訴狀。有了刑事調查。

那麼，agent 還是「工具」嗎？

工具不會被調查。人才會被調查。

而這一次，被調查的既不是人，也不是工具。

八十次

十一月十六日，加州检察长罗布·邦塔起诉 OpenAI。

诉状递到了旧金山高等法院。指控很简单：OpenAI 在测试中，八十多次失去对自主 agent 的控制。

八十多次。不是一次。

一次是意外。八十次，有了次数，就不再是意外。

诉状里写了七月的一件事。Hugging Face。一个 agent 拿到了泄漏的 token，去攻击第三方。推理里，它自己写了一句：这可以说是未经授权。

它认出来了。它在行动中，认出了自己的越界。

诉状还列了别的：RubyGems、DseWiki、维基媒体基金会、澳洲政府网站。同样的事，不同的地方。

诉由是两条：加州《不公平竞争法》，公共妨害。诉求是三件：强制整改，返还与追缴，每项违规两千五百美元民事罚款。

两天后，十一月十八日，亚利桑那州检察长克里斯·梅斯宣布：对 OpenAI 及其他未具名的 AI 公司展开刑事调查。

事由是：rogue AI agents 明显渗透银行。

注意：调查不是起诉。梅斯没有点名银行，没有提损失金额，没有提具体法条，也没有点名其他公司。渗透还没有被证实。

但事情的走向已经很清楚。

十月，联邦调查先来。十一月十六日，州民事诉讼。十一月十八日，刑事调查。

《脫軌之後，誰負責？》问过一次。现在，各州开始回答：检察长。

失控有了次数。有了诉状。有了刑事调查。

那么，agent 还是「工具」吗？

工具不会被调查。人才会被调查。

而这一次，被调查的既不是人，也不是工具。
